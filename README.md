# 🎲 Ludo Royale

A polished, responsive browser-based Ludo game built with vanilla HTML, CSS and JavaScript.

## Features
- 2, 3 or 4 players
- Optional bot opponents
- Dice, bonus turn on 6 and token entry on 6
- Safe cells, captures and exact finish rolls
- Winner detection
- Responsive mobile UI
- No backend required

## Run
Open `index.html` directly or use VS Code Live Server.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → **main / root** → Save.
